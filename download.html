System requirements

  • Windows 10 or 11, 64-bit.
  • NVIDIA graphics card with 6 GB of video memory or more; 16 GB is recommended.
  • About 25 GB of disk space for the app and models, plus 10–16 GB for each 4-hour stream.
  • Internet connection for the installation, downloads and publishing.

Install

  1. Run CutCutSetup-0.1.21.exe. The installer is not signed yet, so Windows may warn about it: press More info → Run anyway.
  2. Choose a folder on a drive with plenty of space. Projects, finished shorts and settings are kept in it, next to the app. No administrator rights are needed.
  3. The installer downloads ffmpeg, the local model runtime and the speech and vision models, about 22 GB, in a console window. If the download stops, run CutCut — проверить и докачать (check and download) from the Start menu: it downloads only what is missing.
  4. Start CutCut from the Start menu. The guide walks you from a stream to a published short.

Activation

CutCut works with an activation code bound to your computer. On the first start it shows the request code of this computer. Send it with an activation code request and paste the activation code you receive. The term of your license is shown in Settings → Computer (Настройки → Компьютер), where a new code can also be entered.

Update

Download the new version and run it: it installs over the current one in the same folder and keeps your projects, shorts, settings and downloaded models.

Uninstall

Open Windows Settings → Apps → Installed apps, find CutCut and press Uninstall. Your projects, shorts and settings stay in the installation folder (projects, shorts and data); delete the folder to remove them too.

What's new in 0.1.21

  • Shuttle playback with J, K and L, up to ×16 forward and backward.
  • Each piece of a layer can have its own crop, position and size.
  • The stream map helps fix the edges of a moment, zooms in on long streams and keeps your marks.
  • All Windows fonts for subtitles, subtitles without punctuation and styles imported from .ass files.
  • Blur an area of the frame, and a check that marks ads, violence and strong language on the timeline.
  • Custom hotkeys, and the look and appearance of a layer from its right-click menu.

All changes are in the release notes.
